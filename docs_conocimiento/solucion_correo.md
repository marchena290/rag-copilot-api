# Guía de Restablecimiento de Correo Institucional
Si un usuario reporta problemas para acceder a su correo institucional o errores de contraseña, siga estos pasos:
1. Verifique que la tecla de Bloqueo de Mayúsculas no esté activada por error.
2. Indique al usuario que ingrese al portal de autoservicio de contraseñas para generar una nueva clave temporal.
3. Si el usuario agotó los intentos y la cuenta está bloqueada, el técnico debe desbloquearla desde el panel de Active Directory.
4. Recuerde al usuario configurar la Autenticación Multifactor (MFA) una vez recupere el acceso.
