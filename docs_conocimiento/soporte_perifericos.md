# Soporte de Hardware: Teclados y Ratones (Mouse)
Procedimiento para fallas en periféricos de entrada:
1. Revise visualmente el estado del cable USB; si el cable está roto o dañado, el equipo debe ser desechado.
2. Desconecte el periférico y conéctelo en un puerto USB diferente de la computadora.
3. Si el equipo sigue sin funcionar, proceda con el reemplazo inmediato solicitando un nuevo teclado o mouse al área de inventario.
4. Actualice el estado del ticket indicando que se realizó un cambio físico de hardware.
