# Diagnóstico de Conexión a Internet
Acciones para resolver la pérdida de conectividad en el equipo del usuario:
1. Verifique si el cable de red (Ethernet) está correctamente conectado tanto a la computadora como al puerto de la pared, o si el adaptador Wi-Fi está encendido.
2. Abra la terminal (CMD) y ejecute `ping 8.8.8.8` para descartar problemas de salida a internet.
3. Reinicie el adaptador de red desde la configuración de Windows.
4. Si varios usuarios en la misma área reportan la caída, comuníquese con el administrador de red para revisar los switches principales.
